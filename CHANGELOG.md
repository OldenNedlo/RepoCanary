# Changelog

All notable changes to RepoCanary are documented here.

## [Unreleased]

### Planned

- richer policy configuration
- additional package-manager checks
- release metadata consistency checks
- optional remote-link validation

## [0.2.0] - 2026-09-09

### Added

- SARIF 2.1.0 output
- `.repocanary.json` policy loading
- ignore patterns for generated/vendor paths
- release-readiness command
- release checks for changelog, CI, tests, version metadata, PR template, and Dependabot configuration
- remediation guidance on findings
- expanded documentation and maintainer workflow examples
- additional automated tests

## [0.1.0] - 2026-09-09

### Added

- initial repository scanner
- community-file checks
- sensitive filename checks
- broken relative Markdown-link checks
- GitHub Actions moving-ref checks
- Python dependency-constraint checks
- large-file and TODO/FIXME signals
- JSON and Markdown reporting
- CI and core test suite
