# Security Policy

## Reporting security issues

Please do not publish secrets, private keys, tokens, personal information, or working exploit details in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use it for security-sensitive reports.

If it is not enabled, open a minimal public issue asking for a private contact channel without including exploit details.

## Scope

RepoCanary is a lightweight repository-maintenance scanner. It does not replace a dedicated secret scanner, dependency vulnerability scanner, static analyzer, or professional security review.
