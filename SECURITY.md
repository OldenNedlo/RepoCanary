# Security Policy

## Reporting security issues

Please do not publish secrets, private keys, tokens, personal information, or working exploit details in a public issue.

If GitHub private vulnerability reporting is enabled, use it for security-sensitive reports. Otherwise, open a minimal public issue asking for a private contact channel without including exploit details.

## Scope

RepoCanary is a lightweight repository-maintenance scanner. It does not replace a dedicated secret scanner, dependency vulnerability scanner, static analyzer, or professional security review.

For the scanner's threat model and trust boundaries, see [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md).
